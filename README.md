# nsh-secure-storage

Secure key-value storage for [Native Shell](https://nsh.dev) apps, in Rust and TypeScript: the platform's own secret store behind one API. It follows the API of [`flutter_secure_storage`](https://github.com/juliansteenbakker/flutter_secure_storage) and addresses the problems reported against it.

This is under construction. `docs/brief-common.md` describes what is being built.
